## Project Overview

DriveWise is a mobile application prototype designed to monitor driving behaviour using a smartphone instead of a separate vehicle tracking device.

The proposed system will allow drivers to record trips, review driving scores, and view previous trips. Parents will be able to monitor the driving activity of their linked drivers.

## Technologies Used

- React Native – Mobile application development
- Expo – Cross-platform development
- TypeScript – Application programming
- Node.js and npm – Development environment
- Git and GitHub – Version control

## Features Implemented in Phase 2

- Driver and Parent role selection
- Driver dashboard with a sample driving score
- Start Trip and End Trip buttons
- Trip duration timer
- Trip history using sample data
- Parent dashboard with sample driver information
- Basic navigation between screens

## Features Planned for Future Sprints

- GPS location and speed tracking
- Acceleration and braking detection
- Driving score calculation
- User authentication and parent-driver account linking
- Database integration
- Trip route visualization using maps

## How to Run the Prototype

1. Install Node.js and npm.
2. Clone this GitHub repository.
3. Open the project folder.
4. Run `npm install`.
5. Run `npx expo start`.
6. Open the application using Expo Go on a compatible mobile device.

For browser testing, install the Expo web dependencies if needed and run `npx expo start --web`.

## Current Development Status

This is an early working prototype developed for Phase 2 of the Systems Analysis and Design project.

The application currently uses demonstration data. GPS tracking, real authentication, persistent database storage, and actual driving behaviour analysis have not yet been implemented.

The prototype has been tested successfully in a web browser.
